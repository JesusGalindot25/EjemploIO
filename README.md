# EjemploIO

Proyecto desarrollado en Java para practicar el manejo de archivos de texto.

## Descripción

El programa permite guardar, leer, eliminar y actualizar registros de alumnos en un archivo de texto llamado `Alumnos_io.txt`.

Cada registro contiene un ID de 5 dígitos y el nombre del alumno.

## Funciones

- **Escribir:** Agrega un nuevo alumno al archivo.
- **Leer:** Muestra los registros guardados.
- **Eliminar:** Elimina un alumno utilizando su ID.
- **Actualizar:** Modifica el nombre de un alumno utilizando su ID.

## Tecnologías utilizadas

- Java
- NetBeans
- Maven
- Java I/O

## Archivo

Los registros se almacenan en `Alumnos_io.txt`.
